# 01 — AI Foundations

A practical introduction to the concepts and systems behind modern artificial intelligence.

This module builds the mental models required for later work with LLM APIs, embeddings, retrieval-augmented generation (RAG), and AI agents.

## Learning outcomes

By completing this repository, you should be able to:

- Distinguish artificial intelligence, machine learning, deep learning, and generative AI.
- Explain the basic training and inference lifecycle.
- Describe datasets, features, labels, parameters, loss, optimization, and generalization.
- Explain neural networks and the transformer architecture at a conceptual level.
- Describe how an LLM processes tokens and generates output.
- Identify common limitations: hallucinations, bias, context limits, and non-determinism.
- Run small, reproducible Python experiments and interpret their results.

## Prerequisites

- Basic programming knowledge.
- Basic command-line and Git usage.
- Python will be introduced and used for experiments; advanced Python is not required.

## Suggested environment

- Python 3.12+
- `uv` or Python `venv`
- JupyterLab or VS Code
- pytest for automated tests

## How to study

For each unit:

1. Read the theory and make sure you can explain the key concepts in your own words.
2. Run the guided experiment.
3. Change at least one variable and record what happens.
4. Complete the independent challenge without copying the solution.
5. Run the tests and save your experiment notes.

## Definition of done

A unit is complete when it contains:

- A concise explanation with references.
- A working, reproducible implementation.
- An experiment report with observations.
- Automated tests where applicable.
- An independent challenge and a short retrospective.
